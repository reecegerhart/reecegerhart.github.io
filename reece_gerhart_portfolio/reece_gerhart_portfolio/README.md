# Reece Gerhart Portfolio

A responsive personal portfolio website built with plain HTML and CSS for GitHub Pages.

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Add `index.html`, `styles.css`, and `README.md` to the root of your GitHub Pages repository.
2. Push the changes to GitHub.
3. Open the repository settings, select Pages, and choose the branch and root folder to publish.
4. Once the site is live, add your custom domain in the Pages settings and configure the DNS records at your domain registrar.

## Before publishing

1. Confirm the project descriptions and skills accurately represent your work.
2. Replace the generic LinkedIn link with your own profile, or remove it.
3. Add a public contact email if you want employers to reach you directly.
4. If a project repository is private or not ready to share, update or remove its link.

The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
